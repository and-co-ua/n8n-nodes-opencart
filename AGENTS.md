# AGENTS.md — n8n community node `n8n-nodes-opencart`

n8n community node package for OpenCart 3. It talks to the OpenCart module `n8n_api`
(separate repository). The API contract lives in that repository's `docs/API.md` and is the
single source of truth — the node implements what is written there.

## Status

- **Version:** 0.1.0
- **Stage done:** 0 — Bootstrap (scaffold from `@n8n/node-cli`, node skeleton, docs).
- **Next:** stage 1 — Core (0.2.0): `OpenCartApi` credentials (store URL, API key,
  auth method), credential test via `system.ping`, request helper, error mapping,
  `api_version` check.

## Architecture

```
OpenCart node ──POST JSON──► {store}/index.php?route=api/n8n
 (execute())                  body: { resource, action, params }
                              key:  X-Api-Key | Authorization: Bearer | body api_key | query api_key
                              resp: { success, data, meta } | { success: false, error: { code, message } }
```

- Programmatic node (`execute()`): one endpoint with a JSON envelope for every operation,
  error unwrapping, `api_version` checks and paging are kept in one request helper.
- **No runtime dependencies** (n8n verification requirement); HTTP only via
  `this.helpers.httpRequestWithAuthentication`.
- `usableAsTool: true`.

## Layout

```
nodes/OpenCart/OpenCart.node.ts     node description + execute()
nodes/OpenCart/OpenCart.node.json   codex (category Sales, docs links)
nodes/OpenCart/opencart(.dark).svg  icons
credentials/                        OpenCartApi credentials (from 0.2.0)
.agents/                            n8n guidelines generated by @n8n/node-cli
```

Every node and credential must be registered in `package.json` → `n8n.nodes` /
`n8n.credentials` (paths in `dist/`).

## Commands

```bash
npm run lint        # n8n-node lint (must pass with zero warnings)
npm run lint:fix
npm run build       # n8n-node build → dist/
npm run dev         # n8n with this node on http://localhost:5678 (hot reload)
```

The dev OpenCart store from the module repository runs on http://localhost:8080.

## Conventions

- Code, comments, commits and docs in English. Conventional Commits.
- Fix lint/type errors instead of disabling rules. Keep `n8n.strict: true`.
- Sensitive credential fields use `typeOptions: { password: true }`; never log secrets.
- `NodeApiError` for API failures, `NodeOperationError` for parameter errors; always pass
  `itemIndex`; support `continueOnFail()`; set `pairedItem`.
- Follow the [UX guidelines](https://docs.n8n.io/integrations/creating-nodes/build/reference/ux-guidelines/).
- Every change in behavior: update `README.md`, this file and `CHANGELOG.md` (`[Unreleased]`).
